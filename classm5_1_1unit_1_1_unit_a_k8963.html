Detailed Description

3-axis magnetometer unit. No standalone GROVE unit exists; it is the magnetometer embedded in the MPU9250 found on early classic M5Stack Core/Fire boards, reachable at 0x0C once the MPU9250's I2C bypass is enabled (see m5::unit::imu::enableAuxBypass)

bool m5::unit::UnitAK8963::wakeup ( )
overridevirtual

Leave power-down.

Returns
True (always)

No-op by design: on the AK8963 power-down is also the state every mode change has to pass through, so there is nothing to undo here. Call startPeriodicMeasurement() to re-enter continuous measurement.

◆ writeMeasurementMode()

bool m5::unit::UnitAK8963::writeMeasurementMode ( const ak8963::MeasurementMode mode,
const ak8963::OutputBit bit )

Write the continuous measurement rate and output bit width.

Parameters
[in]modeContinuous measurement rate
[in]bitOutput bit width
Returns
True if successful

Applied to the chip by the next startPeriodicMeasurement(), along with the periodic measurement interval. Entering a continuous mode is measuring on this chip, so there is no way to park the setting in REG_CNTL1 while stopped – what this does write is the power-down every mode transition has to pass through

Warning
Fails while periodic measurement is running
