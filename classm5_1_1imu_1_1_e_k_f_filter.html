Detailed Description

Quaternion extended Kalman filter (EKF) with gyro bias estimation.

A standard additive EKF with a 7-element state x = [q (4), gyro bias b (3, rad/s internally)] and a 7x7 covariance, re-derived for this repository's coordinate/quaternion convention (see filter_base.hpp): body Z-up, v_world = q.rotate(v_body). Each update() runs:

  • Predict: propagate q via the gyro-minus-bias body rate (reusing m5::math::Quaternion::integrate(), which also renormalizes q – the quaternion is over-parameterized for the 3 rotational degrees of freedom, so per-step renormalization after the linear propagation step is the standard way to keep it on the unit sphere), bias held constant, and propagate the covariance with a first-order state transition Jacobian.
  • Update (accel): sequential 3-axis observation of the predicted gravity direction in the body frame (same expansion as MadgwickFilter/MahonyFilter).
  • Update (mag, when supplied): a second, separate sequential 3-axis observation of the predicted horizontal magnetic field direction, with the world-frame reference (bx, 0, bz) recomputed every step from the current attitude estimate (same "flatten mag to horizontal" trick as MadgwickFilter/MahonyFilter). Both observation updates reuse a single 3x3 (not 6x6) Kalman gain computation (see src/math/matrix.hpp's invert3x3()), which is lighter than solving a combined 6x6 system and keeps the accel and mag corrections independent.

Returns
False (and keeps the previous values) if any parameter is not positive
Note
The gyro_noise_dps parameter is internally scaled by EKF_PROCESS_NOISE_SCALE (currently 100.0x) when building the process noise covariance Q. This means the actual filter response will be stronger (more responsive to references) than the datasheet raw values might suggest; use this method iteratively with your sensor and reference characteristics to tune the desired tracking behavior.
