Detailed Description

3-axis magnetometer unit. No standalone GROVE unit exists for this chip; it is found built into some boards (e.g. classic M5Stack Core/Fire, paired with MPU6886) and as the auxiliary sensor of UnitBMI270

◆ sleep()

bool m5::unit::UnitBMM150::sleep ( )
overridevirtual

Put the chip into suspend mode (REG_POWER_CONTROL power bit cleared)

Returns
True if successful

Works while periodic measurement is running: it is stopped first, since a suspended chip must not be polled. Suspend is the BMM150's lowest power state.

Warning
Suspend resets the register map, so the measurement settings do not survive it; startPeriodicMeasurement() re-applies the preset and data rate.

Reimplemented from m5::imu::IMUDataSource.

Bring the chip out of suspend.

Returns
True if successful

Sets the power bit and waits for the chip to reach sleep mode, where its registers are writable again – measurement stays stopped. Call startPeriodicMeasurement() to reconfigure and resume sampling. Harmless without a preceding sleep().

◆ writeRepetition()

bool m5::unit::UnitBMM150::writeRepetition ( const uint8_t rep_xy,
const uint8_t rep_z )

Write the repetition (oversampling) registers directly.

Parameters
[in]rep_xyREG_REP_XY value; the sensor performs 1 + 2*rep_xy repetitions on X/Y
[in]rep_zREG_REP_Z value; the sensor performs 1 + rep_z repetitions on Z
Returns
True if successful, false if the repetitions cannot keep up with the current data rate

The four presets are only Bosch's recommendations – both registers accept any 8bit value. More repetitions means less noise but a longer measurement, so the pair is rejected when it cannot finish inside one output period (bmm150::repetition_fits()); raise it here by slowing the rate first. Register values, not repetition counts, because nXY can only be odd

Warning
During periodic measurement runs, an error is returned
