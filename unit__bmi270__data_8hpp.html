enum class m5::unit::bmi270::AccelBwp : uint8_t
strong

Accelerometer bandwidth parameter (REG_ACC_CONF register 0x40, bits[6:4])

One field with two meanings, chosen by FilterPerf: a filter setting in Performance mode, an averaging factor in PowerOptimized mode. The averaging-only values are reserved in Performance mode, so the combination is validated (see bwp_fits())
