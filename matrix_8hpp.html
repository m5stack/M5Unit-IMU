Detailed Description

Minimal fixed-size matrix arithmetic (framework independent)

Header-only, heap-free (std::array backed) fixed-size matrix type, providing only what src/imu/filter/ekf.hpp needs: element access, addition, subtraction, scalar and matrix multiplication, transpose, and identity for square matrices. General NxN inversion is intentionally not provided; instead two narrow numerical primitives are exposed as free functions:

  • invert3x3(): closed-form 3x3 inverse, for a single 3-axis observation update (e.g. accel, then mag as a separate sequential step)
  • cholesky_solve(): solves A*x = b for a symmetric positive-definite A of any fixed size via Cholesky decomposition, for callers that prefer a single combined observation update (e.g. a 6x6 accel+mag innovation covariance) instead of two sequential 3x3 updates

Closed-form inverse of a 3x3 matrix.

Parameters
mMatrix to invert
[out]outInverse of m; only written on success
Returns
False if m is (near) singular (determinant magnitude below MATRIX_ZERO_EPSILON), leaving out unwritten
Note
The singularity threshold MATRIX_ZERO_EPSILON is 1e-9 (absolute determinant magnitude). Matrices with very small scale (e.g., condition number > 1e9) will be treated as singular; the caller should handle failure gracefully by skipping the update (as in EKFFilter::apply_axis3_update()), which is safe because the Kalman gain computation is optional for each observation.
