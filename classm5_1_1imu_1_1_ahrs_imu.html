Detailed Description

AhrsController plus an M5Unified IMU_Class-compatible API.

Use this in place of AhrsController when porting M5Unified M5.Imu code: it is-a AhrsController (so it plugs into presets, add(), selectFilter(), etc. unchanged) and additionally exposes getAccel/getGyro/getMag/getTemp/getImuData/getAhrsData/setCalibration. The getters read the already axis-corrected, offset-compensated latest() sample; setCalibration forwards to writeAutoCalibration(); getAhrsData() provides the attitude output for the getAhrsData() slot that M5Unified's IMU_Class declares but does not implement.

enum m5::imu::AhrsImu::axis_t

A source axis with a sign, layout-compatible with m5::IMU_Class::axis_t.

Bit 0 is the sign (1 = negated), bits 1-2 select the axis (0 = X, 1 = Y, 2 = Z).
