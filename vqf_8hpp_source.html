19// The vendored vqf.hpp (see src/imu/filter/third_party/vqf, MIT license, unmodified from
20// https://github.com/dlaidig/vqf) picks its floating-point type `vqf_real_t` (used for every
21// VQF member, including its in-memory layout) based on whether VQF_SINGLE_PRECISION is
22// defined *at the point vqf.hpp is included* -- defaulting to `double` otherwise. Defining it
23// here, right before the only include of the vendored header in this adapter's public header,
24// makes every translation unit that includes this file (the adapter's .cpp, and its tests)
25// see `vqf_real_t == float`, matching this repository's float-based AhrsFilterBase. This must
26// stay consistent with third_party/vqf/vqf_impl.cpp, which defines the same macro before
27// compiling the vendored implementation itself (see that file for why both sides need to agree).

29#define VQF_SINGLE_PRECISION
30#endif
