enum class m5::unit::ak8963::MeasurementMode : uint8_t
strong

Continuous measurement rate, the subset of Mode this driver measures in.

Mode itself is the raw CNTL1 nibble and includes states the driver owns (FuseRom backs the ASA read, PowerDown backs every mode transition), so only the two continuous rates are offered here. The difference is almost entirely power: a measurement draws 5mA for 7.2ms, so Cont100Hz (10ms period) is on nearly all the time while Cont8Hz (125ms) has a ~6% duty cycle

Output bit width (CNTL1 bit4 BIT)

Full scale is +/-4912µT either way; only the resolution changes. 14bit output is sign-extended and right-aligned, so it needs no shifting – just the coarser sensitivity below
