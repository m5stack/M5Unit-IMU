Detailed Description

Thin contract between measurement units and consumers (e.g. AHRS)

Implementations report their capability, hand out unconsumed raw samples in oldest-first order (pop semantics), and expose conversion coefficients. User-defined sources only need to implement those three methods to plug into the AHRS layer; sleep()/wakeup() are optional and default to doing nothing.

virtual bool m5::imu::IMUDataSource::sleep ( )
inlinevirtual

Put the device into its lowest reversible power state.

Returns
True if this source implements sleeping and the device accepted it

Optional: the default does nothing and returns false, so sources that cannot be suspended stay safe to aggregate. Implementations leave the device producing no samples while asleep. Periodic measurement is stopped; wakeup() does not restore it and callers must invoke startPeriodicMeasurement() again to resume sampling.

virtual bool m5::imu::IMUDataSource::wakeup ( )
inlinevirtual

Bring the device back from sleep()

Returns
True if this source implements waking and the device accepted it

Optional: the default does nothing and returns false. Implementations bring the device back to a configurable state; they do not restore the measurement mode that was active before sleep(). Callers must invoke startPeriodicMeasurement() again to resume sampling. Calling this without a preceding sleep() must be harmless.
