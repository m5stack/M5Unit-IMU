Detailed Description

6-axis (accel + gyro) IMU unit. CoreS3/AtomS3R built-in

Note
Accel/gyro/temp only. The chip's auxiliary (AUX) interface, which can drive an on-chip BMM150 magnetometer, is deliberately left untouched here – use UnitBMI270AuxBMM150 on the boards that wire one to it (CoreS3, AtomS3R, Mini IMU-Pro). Enabling it is not always safe: on UnitDoF9/UnitDoF10 the AUX pins share the main I2C bus, and switching the interface on makes the BMI270 a second bus master, locking the bus until the unit is power-cycled

◆ sleep()

bool m5::unit::UnitBMI270::sleep ( )
overridevirtual

Suspend the chip (REG_PWR_CTRL off, REG_PWR_CONF adv_power_save)

Returns
True if successful

Works while periodic measurement is running: it is stopped first, since a suspended chip must not be polled. Then accel/gyro/temp are powered down and advanced power save is enabled. The uploaded configuration file survives suspend – unlike softReset(), which requires the full post-reset initialization again.

Reimplemented from m5::imu::IMUDataSource.

Resume the chip from sleep()

Returns
True if successful

Leaves advanced power save (configuration writes are ignored while it is active) and powers accel/gyro/temp back on – measurement stays stopped. Call startPeriodicMeasurement() to resume sampling. Harmless without a preceding sleep().
