Detailed Description

NXP/Freescale MAG3110 3-axis magnetometer. No standalone GROVE unit exists; it is the magnetometer on the original (2017) classic M5Stack Gray (paired with an MPU6050). It sits directly on the host I2C bus at 0x0E (no aux bypass needed, unlike the MPU9250's AK8963).

Leave STANDBY.

Returns
True (always)

No-op by design: on the MAG3110 STANDBY is also the state the chip has to be in to be configured, so there is nothing to undo here. Call startPeriodicMeasurement() to enter ACTIVE continuous measurement.

◆ writeDataRate()

bool m5::unit::UnitMAG3110::writeDataRate ( const mag3110::DataRate rate,
const mag3110::OverSampling os )

Write the output data rate and over sampling ratio.

Parameters
[in]rateOutput data rate
[in]osOver sampling ratio
Returns
True if successful

Applied to the chip immediately, and to the periodic measurement interval

Warning
Fails while periodic measurement is running. Every REG_CTRL_REG1 field except AC can only be changed in STANDBY, and a write attempted in ACTIVE is silently ignored rather than reported – so this drops the chip to STANDBY itself instead of trusting inPeriodic(), which says nothing about AC (stopPeriodicMeasurement() leaves the chip running by design; sleep() is what stops it)
Note
The datasheet notes the first output period after leaving STANDBY reads slightly off
