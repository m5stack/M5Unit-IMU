bool m5::unit::bmi270::detectAddress ( ReadReg read,
uint8_t & addr )

Detect which I2C address a built-in BMI270 uses on a bus (0x68 or 0x69, board-dependent)

Probes both candidate addresses by reading CHIP_ID and reports the one where a BMI270 answers. Framework-agnostic: the caller injects the bus read, so the unit library stays free of M5Unified / Arduino Wire. Hand the detected address to the constructor:

uint8_t a{};
if (m5::unit::bmi270::detectAddress(read, a)) { m5::unit::UnitBMI270 unit{a}; }
