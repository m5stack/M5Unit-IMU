Detailed Description

Gradient-descent orientation filter (Madgwick 2010)

Implements the gradient descent algorithm from S. Madgwick's "An efficient orientation filter for inertial and inertial/magnetic sensor arrays" (2010), re-derived for this repository's coordinate/quaternion convention (see filter_base.hpp): body Z-up, v_world = q.rotate(v_body). Each update() blends a gyro-integrated quaternion rate with a gradient-descent correction step that drives the predicted reference direction(s) (gravity, and – when a magnetometer sample is supplied – the horizontal magnetic field recomputed every step from the current attitude estimate) toward the measured accel/mag directions.
