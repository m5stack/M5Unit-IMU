Detailed Description

M5Unified-compatible facade over AhrsController.

AhrsImu derives from AhrsController and adds thin forwarders that mirror m5::IMU_Class method names, signatures and data layout, so code written against M5Unified's M5.Imu ports here with minimal churn. All M5Unified vocabulary (the get/set spelling and the imu_data_t/imu_3d_t types) is confined to this file; AhrsController itself stays free of any M5Unified concept and keeps this library's write/read convention. This header pulls in no M5Unified source – the forwarders are built purely on AhrsController's public API (latest(), euler(), writeAutoCalibration(), and the hasAccel()/hasGyro()/hasTemp()/hasValidMag()/lastMicros() queries).
