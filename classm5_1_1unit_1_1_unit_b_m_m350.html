◆ sleep()

bool m5::unit::UnitBMM350::sleep ( )
overridevirtual

Put the chip into suspend mode (REG_PMU_CMD suspend)

Returns
True if successful

Works while periodic measurement is running: it is stopped first, since a suspended chip must not be polled. Suspend is the BMM350's lowest power state and preserves the register map, so the OTP compensation data and the configured ODR/averaging survive it.

Reimplemented from m5::imu::IMUDataSource.

◆ softReset()

bool m5::unit::UnitBMM350::softReset ( )

Soft reset (REG_CMD CMD_SOFTRESET), then re-run the mandatory post-reset initialization (OTP download and magnetic reset (BR/FGR)), leaving the chip initialized but unconfigured and stopped.

Returns
True if successful
Warning
During periodic measurements, an error is returned; call stopPeriodicMeasurement() first
All settings revert to the chip defaults; call startPeriodicMeasurement(...) to reconfigure and resume measurement
