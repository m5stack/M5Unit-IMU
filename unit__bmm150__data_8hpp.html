uint32_t m5::unit::bmm150::measurement_time_us ( const uint8_t rep_xy,
const uint8_t rep_z )
constexpr

Active measurement time (us) for the given repetition register values.

Bosch's timing relation, which reproduces every "max ODR in forced mode" figure in the datasheet's preset table: Regular (9/15) -> 9.8ms = 102Hz, HighAccuracy (47/83) -> 49.3ms = 20Hz. A measurement that cannot finish inside one output period is simply not written to the data registers (datasheet 4.2.4), so this is what bounds the usable rate – see repetition_fits()
