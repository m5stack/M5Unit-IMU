enum class m5::imu::AxisPermutation : uint8_t
strong

Which raw axis feeds each output slot, read left-to-right.

e.g. YXZ means output[0] = raw Y, output[1] = raw X, output[2] = raw Z.

Enumerator

Compose two axis orders into one.

Parameters
firstAxis order applied first
secondAxis order applied second
Returns
An AxisOrder R such that R.apply(v) == second.apply(first.apply(v)) for every v

AxisOrder is a signed axis permutation, so the composition is itself an AxisOrder (no information is lost). Used by AhrsController to fold a global user axis order onto each source's fixed board correction without applying two transforms per sample.
