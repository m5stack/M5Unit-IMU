Detailed Description

Angle-based first-order complementary filter.

Blends the gyro-integrated angle with a reference angle independently for roll, pitch and yaw: angle = alpha * (angle + gyro * dt) + (1 - alpha) * angle_ref. Roll/pitch reference angles come from the accelerometer; the yaw reference comes from a tilt-compensated magnetometer heading when a magnetometer sample is supplied (pure gyro integration otherwise). See filter_base.hpp for the unit and coordinate convention this filter assumes.
