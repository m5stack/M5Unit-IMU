Detailed Description

Shared base for the TDK InvenSense MPU 6-axis family (accel + gyro + temp)

The accel/gyro register map, init sequence, and periodic read are identical across MPU6886/6050/6500 (and the MPU9250 accel/gyro die), so they all live here. The only per-chip differences – the accepted WHO_AM_I id and the temperature scale – are exposed as virtual hooks (accepts_whoami / temperature_res / temperature_offset) that thin derived classes override. Not instantiated directly; use UnitMPU6886 / UnitMPU6050 / UnitMPU6500 / UnitMPU9250.

◆ sleep()

bool m5::unit::UnitMPU6xxx::sleep ( )
overridevirtual

Put the chip to sleep (REG_PWR_MGMT_1 SLEEP)

Returns
True if successful

Works while periodic measurement is running: it is stopped first, since a sleeping chip must not be polled. The SLEEP bit then halts sampling and drops the chip to its low-power state. Unlike softReset() the configuration is preserved.

Reimplemented from m5::imu::IMUDataSource.

Wake the chip from sleep()

Returns
True if successful

Only clears SLEEP (by selecting the PLL clock) and waits for the sensors to start up – measurement stays stopped. Call startPeriodicMeasurement() to resume sampling. Harmless without a preceding sleep().
